CASE STUDY / BUSINESS WEB APPLICATION

E-kinerja System

A digital performance management system built to make it easier to record, monitor, and approve employees' daily work data through a structured, tiered approval workflow.

ClientBKN
StackPHP · CodeIgniter · MySQL
StatusProfessional project
LinkInternal Project
01 / The challenge

The problem behind the interface.

Daily performance recording, monitoring and approval were handled manually, making it hard to keep data accurate, auditable and easy to report on. The system needed to digitize this process end to end and give every role — staff, department head and admin — a clear, structured way to work with performance data.

02 / The solution

From workflow to software.

I worked across the application layer and database, implementing the interfaces, business logic and data flows needed for daily operations. The system runs on a tiered approval workflow: staff input daily work data, department heads review and approve it, and the system keeps status, notifications and reporting in sync — creating a clear audit trail for every activity along the way.

03 / The result

Built for the people using it.

The resulting system supports day-to-day monitoring, gives staff and department heads a transparent approval process, and provides accurate, real-time performance reports — improving administrative efficiency across the organization.

04 / Application objectives

What the system set out to do.

Digitize the process of recording employees' daily performance and run an efficient, transparent approval system. Beyond that, it was built to provide accurate, real-time performance reports, improve administrative efficiency and monitoring, and create a clear audit trail for every work activity.

05 / System workflow

How data moves through the system.

Staff input their daily work data, which triggers a notification to the department head. The department head reviews and approves it, the system updates the status and notifies staff, and reports can then be generated by staff or department heads — with admins monitoring and managing the system throughout.

# HeroKoding — Minimal Developer Portfolio

Static portfolio redesign based on the information currently published at:
https://herokoding.netlify.app/

## Design direction

Minimal editorial + developer / terminal details:
- Manrope for display/body
- DM Mono for technical metadata
- warm off-white background
- thin borders
- restrained green accent
- terminal micro-interaction
- responsive mobile navigation
- no framework or build step

## Run

Just open `index.html` in a browser.

For local development, any static server works, for example:

python3 -m http.server 8080

Then open http://localhost:8080

## Customize

Edit:
- `index.html` — content, projects, experience, contact
- `assets/css/style.css` — visual design
- `assets/js/main.js` — interactions

## Note

Project names and professional information are based on the public content visible on the existing HeroKoding portfolio. Project descriptions in this redesign are intentionally concise and should be adjusted to your exact project details/screenshots/links.

Project Overview

  • QR Food System is a web-based application that automates the process of recording employees' daily performance.
  • It provides a user-friendly interface for staff members to input their work data and generate reports.
  • The application features a simple and intuitive interface, making it easy for staff members to input their work data and generate reports.

Application Objectives

  • Make it easier for customers to order canteen menus digitally without having to queue for a long time.
  • Provide a fast, secure, and practical QR payment system for food purchase transactions.
  • Provide an automatic queue number so orders can be processed in an orderly and efficient manner.
  • Improve canteen operational efficiency through integrated order recording and order status management.

System Workflow

  1. User: Selects canteen menu online via the app or website.
  2. User: Makes payment using QR (scan & pay) directly from their phone.
  3. System: Issues an automatic queue number for orders processed at the canteen.
  4. Canteen Staff: Receive order notifications and process them according to the queue number.
  5. System: Updates order status and notifies the user when the order is ready for pickup.
  6. Administrator: Monitors transactions, queues, and manages menus and reports.

  • Back-End: Codeigniter, MySQL
  • Other Tools: Bootstrap, jQuery, Git
